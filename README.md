# xv-deploy

Electron-приложение для деплоя проекта в один клик. Чёрно-белый интерфейс.

## Запуск

```bash
npm install
npm start
```

Сборка установщика: `npm run build`

## Как пользоваться

1. Нажми **Выбрать папку** и укажи папку проекта (команда сборки и папка результата подставятся сами).
2. Выбери сервис: Vercel, Netlify, Cloudflare Pages, Firebase Hosting, GitHub Pages, Surge, Railway, Fly.io.
3. При необходимости поправь команду сборки и папку с результатом.
4. Нажми **Деплой →** и следи за логом. Ссылки на готовый сайт появятся внизу.

## Заметки

- Нужен установленный Node.js (используется `npx`). Для Railway и Fly.io нужны их CLI.
- Для первого деплоя на сервис может понадобиться войти в аккаунт (`npx vercel login`, `npx netlify login` и т.д.) в терминале.
- Новый сервис добавляется одной записью в `services.js`.

## Профили

После выбора сервиса под плитками появляется строка **Профиль**. Нажми **+ Профиль**, заполни название и данные
(токен, ID проекта/аккаунта и т.д. — набор полей зависит от сервиса), сохрани. Профилей может быть сколько угодно
(«Личный», «Работа»), переключаются в один клик. **По умолчанию** — используется вход, который уже сделан в CLI.

Профили хранятся в папке данных приложения (`profiles.json`), токены не показываются в интерфейсе после сохранения.
Значения передаются сервису через переменные окружения или флаги команды только на время деплоя.
